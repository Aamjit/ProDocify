## 🚀 Quick Start

1. Install: `npm install`
2. Setup .env: `cp .env.example .env`
3. Migrate: `npm run prisma:migrate:dev -- --name initial`
4. Run: `npm run dev`
5. API: http://localhost:3000/api/docs

See `docs/00_START_HERE.md` for details.
